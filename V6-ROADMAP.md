# V6 data foundation
No live feed credentials or commercial agreements are included. Retail importer accepts local CSV files only; use --authorised after checking redistribution rights. Match groups are candidates, not proof of identity. Compare pack, condition and variant; missing identifiers do not match. Prices exclude delivery unless supplied separately. Never put credentials in public files.

Run: python -m unittest -v
Import: python retail.py authorised-feed.csv --authorised
